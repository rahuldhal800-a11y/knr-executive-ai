# KNR AEGIS AI ⚡

**AEGIS — Agentic Executive & General Intelligence System**

The `mobile/` application is a no-hosted-API browser/PWA experiment. It can request camera and microphone permissions after explicit user interaction and can attempt on-device WebGPU inference using WebLLM.

**Important:** this is not unrestricted phone access. Android/browser permissions control camera and microphone. On-device inference depends on compatible WebGPU support and device memory. The first model load can download substantial model weights.

The main AEGIS agent platform, provider router, cybersecurity skills, device capability ACLs, and reproducible model-training pipeline remain in the repository.
