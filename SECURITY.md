# Security Policy

AEGIS is intended for defensive and authorized use.

Do not open a public issue containing credentials, exploit details, or sensitive data. Use GitHub's private security reporting mechanism when available.

Report vulnerabilities affecting the agent runtime, provider routing, tool permissions, device adapters, training pipeline, dependency supply chain, or data handling.

Security evaluations should test prompt injection, tool authorization, data leakage, unsafe tool chaining, and privilege escalation.
