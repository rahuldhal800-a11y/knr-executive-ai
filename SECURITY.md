# Security Policy

AEGIS is intended for defensive and authorized use.

## Reporting a vulnerability

Do not open a public issue containing credentials, exploit details, or sensitive data. Contact the repository owner through GitHub's private security reporting mechanism when available.

## Scope

Report vulnerabilities affecting the agent runtime, provider routing, tool permissions, device adapters, training pipeline, dependency supply chain, or data handling.

## Model safety

Security evaluations should test prompt injection, tool authorization, data leakage, unsafe tool chaining, and privilege escalation. A capability is not considered complete until its permission model and tests are documented.
