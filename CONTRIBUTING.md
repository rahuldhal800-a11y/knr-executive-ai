# Contributing to AEGIS

## Principles

- Prefer small, testable changes.
- Every tool needs a clear permission boundary and failure mode.
- Never commit API keys, credentials, personal data, or generated secrets.
- New model behavior must include evaluation cases.
- Preserve reproducibility: record model, dataset, configuration, and benchmark versions.

## Pull requests

Describe the problem, implementation, tests, and any changes to model behavior. For new agent capabilities, document required permissions and expected side effects.
